Tips & Tricks

How to set up the wheel in OBS

Copy the Wheel overlay URL above and add it as a Browser Source in OBS. Set the width and height to 600x600 (or your preferred size). Make sure "Shutdown source when not visible" is unchecked so the wheel stays connected. Do the same for the Delay timer overlay if you want viewers to see the cooldown countdown.

Why is there no sound on the wheel?

Browsers block audio until a user interacts with the page. In OBS Browser Sources, audio plays automatically. If you're testing in a regular browser, click anywhere on the page first to unlock audio. You can also enable "Control audio via OBS" in the Browser Source properties.

How do prize tiers work?

You can create multiple prize tiers based on gift amounts. For example: 5 gifts triggers a "Basic" wheel, 25 gifts triggers a "Premium" wheel with better prizes, and 50 gifts triggers a "Legendary" wheel with ridiculous rewards. When someone gifts subs, the app picks the highest tier their gift count qualifies for. Each tier has its own set of prizes — fully customizable.

How do weights work?

Each prize has a weight that determines its probability. Weights are normalized to percentages (they always add up to 100%). A prize with weight 50 in a list totaling 200 has a 25% chance. Use the "Normalize to 100%" button to see the actual percentages. Weights are normalized per tier, so each tier is independent.

What is "Bonus spin"?

If a prize is marked as bonus, landing on it triggers another spin automatically — the viewer gets a second chance! The bonus spin uses the same tier as the original spin. Great for keeping things exciting.

Customizing your wheel

Pick an accent color to personalize the wheel to match your brand. The color applies to the wheel pegs, pointer, segment tints, and also the delay overlay highlight. The accent color is shared across all tiers.

Testing with "Send Gifts"

Use the Send Gifts action to simulate a gift event. Enter the number of gifts (e.g. 5, 25, or 50) and the app will match it to the correct tier, just like a real Kick gift event. Use Send Test Spin for a quick spin without tier logic.

What does "Reset Delay Timer" do?

After each spin, there's a 5-minute cooldown before the next spin fires. If you want to skip the wait (e.g. during testing), hit Reset Delay Timer to clear it. If there are pending spins, one will fire immediately with the correct tier.
